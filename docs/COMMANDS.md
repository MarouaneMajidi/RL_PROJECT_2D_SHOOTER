## 1. Main Game

### Manual Play (`main.py`)

Play the zombie shooter game manually or with a trained PPO agent.

```bash
# Manual mode (keyboard/mouse control)
python main.py --mode manual

# Agent mode (PPO agent plays automatically)
python main.py --mode agent

# Agent mode with specific model
python main.py --mode agent --model checkpoints/player_ppo/best_model.pth
```

**Options:**

- `--mode`: Game mode (`manual` or `agent`, default: `manual`)
- `--model`: Path to trained PPO model (default: `checkpoints/best_model.pth`)

**Controls (Manual Mode):**

- WASD or Arrow Keys: Move
- Mouse: Aim
- Left Click: Shoot
- 1/2/3: Switch weapon (Pistol/Machine Gun/Knife)
- R: Restart
- ESC: Quit

## 2. Feature-Based Agents

### Train Feature-Based PPO Agent (`scripts/train_ppo.py`)

Train a PPO agent using hand-crafted features.

```bash
# Basic training (1M timesteps)
python scripts/train_ppo.py

# Training with rendering
python scripts/train_ppo.py --render

# Resume from checkpoint
python scripts/train_ppo.py --checkpoint checkpoints/player_ppo/checkpoint_500000.pth

# Training with GPU and custom hyperparameters
python scripts/train_ppo.py --device cuda --timesteps 2000000 --lr 1e-4 --batch-size 128
```

**Options:**

- `--timesteps`: Total timesteps to train (default: `1000000`)
- `--render`: Enable rendering during training
- `--checkpoint`: Path to checkpoint to resume training
- `--device`: Device to use (`cuda` or `cpu`, default: `cpu`)
- `--lr`: Learning rate (default: `3e-4`)
- `--batch-size`: Batch size (default: `64`)
- `--n-steps`: Steps per rollout (default: `2048`)

**Output Files:**

- Models: `checkpoints/player_ppo/best_model.pth`, `checkpoints/player_ppo/checkpoint_*.pth`
- Logs: `logs/training_YYYYMMDD_HHMMSS.log`

### Train Feature-Based DDA Agent (`scripts/train_dda.py`)

Train a DDA agent using hand-crafted features to dynamically adjust game difficulty.

```bash
# Basic training
python scripts/train_dda.py

# Training with specific player model
python scripts/train_dda.py --player-model checkpoints/player_ppo/best_model.pth

# Training with rendering
python scripts/train_dda.py --render

# Resume from checkpoint
python scripts/train_dda.py --checkpoint checkpoints/dda/checkpoint_50000.pth
```

**Options:**

- `--player-model`: Path to trained player agent (default: `checkpoints/best_model.pth`)
- `--checkpoint`: Path to DDA checkpoint to resume training
- `--render`: Enable rendering during training

**Prerequisites:**

- A trained PPO agent must exist (generated by `scripts/train_ppo.py`)

**Output Files:**

- Models: `checkpoints/dda/best_dda_model.pth`, `checkpoints/dda/checkpoint_*.pth`
- Logs: `logs/training_YYYYMMDD_HHMMSS.log`

### Test Feature-Based PPO Agent (`scripts/test_agent.py`)

Evaluate performance of a trained feature-based PPO agent.

```bash
# Basic test (10 episodes)
python scripts/test_agent.py --model checkpoints/player_ppo/best_model.pth

# Extended test (100 episodes, no rendering)
python scripts/test_agent.py --model checkpoints/player_ppo/best_model.pth --episodes 100 --no-render

# Test with stochastic policy
python scripts/test_agent.py --model checkpoints/player_ppo/best_model.pth --stochastic
```

**Options:**

- `--model`: Path to model checkpoint (required)
- `--episodes`: Number of test episodes (default: `10`)
- `--no-render`: Disable rendering for faster testing
- `--stochastic`: Use stochastic policy instead of deterministic

**Output Statistics:**

- Average Reward
- Average Episode Length
- Average Zombie Kills
- Best/Worst Reward

### Play with Feature-Based DDA (`play_with_dda.py`)

Play manually while DDA agent adjusts difficulty in real-time.

```bash
# Play with default DDA model
python play_with_dda.py

# Play with specific DDA model
python play_with_dda.py --model checkpoints/dda/best_dda_model.pth
```

**Options:**

- `--model`: Path to DDA model (default: `checkpoints/dda/best_dda_model.pth`)

**Display Information:**

- DDA Action: Current difficulty adjustment
- Zombie Speed: Current zombie velocity
- Spawn Rate: Current spawn frequency

### Test Feature-Based DDA (`test_dda.py`)

Test DDA system in manual or agent mode.

```bash
# Manual mode (human player)
python test_dda.py --mode manual

# Agent mode (PPO agent plays)
python test_dda.py --mode agent

# Agent mode with specific models
python test_dda.py --mode agent --dda-model checkpoints/dda/best_dda_model.pth --player-model checkpoints/player_ppo/best_model.pth
```

**Options:**

- `--mode`: Test mode (`manual` or `agent`, default: `manual`)
- `--dda-model`: Path to DDA model (default: `checkpoints/dda/best_dda_model.pth`)
- `--player-model`: Path to player model for agent mode (default: `checkpoints/best_model.pth`)

## 3. CNN-Based Agents

### Train CNN-Based Player Agent (`scripts_cnn/train_player_cnn.py`)

Train a PPO agent using CNN on raw game screenshots.

```bash
# Basic training (1M timesteps)
python scripts_cnn/train_player_cnn.py

# Training with GPU and custom parameters
python scripts_cnn/train_player_cnn.py --device cuda --timesteps 2000000 --lr 1e-4

# Resume from checkpoint
python scripts_cnn/train_player_cnn.py --checkpoint checkpoints_cnn/player_cnn/checkpoint_500000.pth

# Training with rendering
python scripts_cnn/train_player_cnn.py --render
```

**Options:**

- `--timesteps`: Total timesteps to train (default: `1000000`)
- `--render`: Enable rendering during training
- `--checkpoint`: Path to checkpoint to resume training
- `--device`: Device to use (`cuda` or `cpu`, default: `cuda`)
- `--lr`: Learning rate (default: `3e-4`)
- `--batch-size`: Batch size (default: `64`)
- `--n-steps`: Steps per rollout (default: `2048`)

**Output Files:**

- Models: `checkpoints_cnn/player_cnn/best_model.pth`, `checkpoints_cnn/player_cnn/checkpoint_*.pth`
- Logs: `logs/training_YYYYMMDD_HHMMSS.log`

### Train CNN-Based DDA Agent (`scripts_cnn/train_dda_cnn.py`)

Train a DDA agent using CNN on raw game screenshots.

```bash
# Basic training
python scripts_cnn/train_dda_cnn.py

# Training with specific player model
python scripts_cnn/train_dda_cnn.py --player-model checkpoints_cnn/player_cnn/best_model.pth

# Training with rendering
python scripts_cnn/train_dda_cnn.py --render

# Resume from checkpoint
python scripts_cnn/train_dda_cnn.py --checkpoint checkpoints_cnn/dda_cnn/checkpoint_50000.pth

# Training with timestep limit
python scripts_cnn/train_dda_cnn.py --timesteps 500000
```

**Options:**

- `--player-model`: Path to trained player agent (default: `checkpoints_cnn/player_cnn/best_model.pth`)
- `--checkpoint`: Path to DDA checkpoint to resume training
- `--render`: Enable rendering during training
- `--episodes`: Maximum training episodes (overrides timesteps if specified)
- `--timesteps`: Maximum training timesteps

**Prerequisites:**

- A trained CNN-based player agent must exist

**Output Files:**

- Models: `checkpoints_cnn/dda_cnn/best_model.pth`, `checkpoints_cnn/dda_cnn/checkpoint_*.pth`

### Test CNN-Based Player Agent (`scripts_cnn/test_player_cnn.py`)

Evaluate performance of a trained CNN-based player agent.

```bash
# Basic test (10 episodes)
python scripts_cnn/test_player_cnn.py --model checkpoints_cnn/player_cnn/best_model.pth

# Extended test (50 episodes, no rendering)
python scripts_cnn/test_player_cnn.py --model checkpoints_cnn/player_cnn/best_model.pth --episodes 50 --no-render

# Test with stochastic policy
python scripts_cnn/test_player_cnn.py --model checkpoints_cnn/player_cnn/best_model.pth --stochastic
```

**Options:**

- `--model`: Path to CNN model checkpoint (required)
- `--episodes`: Number of test episodes (default: `10`)
- `--no-render`: Disable rendering
- `--stochastic`: Use stochastic policy

### Test CNN-Based DDA Agent (`scripts_cnn/test_dda_cnn.py`)

Test CNN-based DDA agent with a player agent.

```bash
# Basic test (5 episodes)
python scripts_cnn/test_dda_cnn.py --dda-model checkpoints_cnn/dda_cnn/best_model.pth

# Test with specific player model
python scripts_cnn/test_dda_cnn.py --dda-model checkpoints_cnn/dda_cnn/best_model.pth --player-model checkpoints_cnn/player_cnn/best_model.pth

# Extended test without rendering
python scripts_cnn/test_dda_cnn.py --dda-model checkpoints_cnn/dda_cnn/best_model.pth --episodes 20 --no-render

# Test with stochastic policy
python scripts_cnn/test_dda_cnn.py --dda-model checkpoints_cnn/dda_cnn/best_model.pth --stochastic
```

**Options:**

- `--dda-model`: Path to CNN DDA model (required)
- `--player-model`: Path to player model (optional, uses feature-based if not specified)
- `--episodes`: Number of test episodes (default: `5`)
- `--no-render`: Disable rendering
- `--stochastic`: Use stochastic policy

## 4. Evaluation and Analysis

### User Evaluation Session (`scripts/test_session.py`)

Run user evaluation sessions comparing gameplay with and without DDA.

```bash
# Start evaluation session
python scripts/test_session.py
```

**Workflow:**

1. Automatic player ID assignment
2. Two matches (one with DDA, one without, randomized order)
3. Subjective questionnaires after each match
4. Final preference selection

**Data Collection:**

- Metrics: `data/evaluation/all_metrics.json`
- Frame data: `data/evaluation/all_frames.json`
- Responses: `data/evaluation/all_answers.json`
- Preferences: `data/evaluation/all_preferences.json`

### Find Best Feature-Based Model (`find_best_manual_model/test_manual_models.py`)

Evaluate and compare multiple feature-based agent models.

```bash
# Test all models in checkpoints directory
python find_best_manual_model/test_manual_models.py
```

**Output:**

- Results: `find_best_manual_model/test_results.csv`
- Notebook: `find_best_manual_model/best_model_overall.ipynb`

### Find Best CNN Model (`find_best_CNN/test_cnn_models.py`)

Evaluate and compare multiple CNN-based agent models.

```bash
# Test all CNN models in checkpoints_cnn directory
python find_best_CNN/test_cnn_models.py
```

**Output:**

- Results: `find_best_CNN/test_comparaison_cnn_results.csv`
- Notebook: `find_best_CNN/best_cnn.ipynb`

### Evaluate DDA Agents (`evaluate_find_best_dda/evaluate_dda_agents.py`)

Comprehensive evaluation of DDA agents across multiple metrics.

```bash
# Run DDA evaluation
python evaluate_find_best_dda/evaluate_dda_agents.py
```

**Output:**

- Evaluation data: `evaluate_find_best_dda/data/`
- Analysis notebook: `evaluate_find_best_dda/analyze_dda_evaluation.ipynb`
- Visualization plots: `evaluate_find_best_dda/*.png`

### Visualize Training Metrics

Visualize training progress for feature-based agents.

```bash
# Visualize PPO training metrics
python scripts/visualize_training_metrics.py

# Visualize DDA training metrics
python scripts/visualize_dda_training_metrics.py
```

- All commands should be executed from the project root directory
- Model paths are relative to the project root
- Use `--help` flag on any script for additional information
- Training logs are automatically saved with timestamps
- GPU training recommended for CNN-based agents (`--device cuda`)
